(1) `Plant.measurement(state, bk=None)` = the TRUE sensor model h (default None), same contract as dynamics: bk-aware, batch-capable ((n_x,)/(N,n_x) in, same rank out) because the EKF differentiates h with a probe batch and the UKF pushes its sigma batch through it. (3) `StateEstimator.measure(state)` = the estimator's belief about h, used by the sim to synthesize the sensor: base identity; KF/Luenberger C@x; EKF/UKF h(x). The runner (iter_scenario) calls est.attach_plant(plant) once, then feeds `_inject_noise(np.asarray(est.measure(true_state)), noise_cfg, rng)` instead of get_state(). WHY est.measure not plant.measurement directly: the scenario chooses the sensor; pendulum_balance's KF has C=I (feeds the full state), so applying the plant's bob-position h unconditionally would break it. est.measure keeps sim+filter consistent by construction and is byte-identical for linear scenarios.
